🛠️ Hardware Store - Application Documentation

1. Application Overview

This e-comerce application allows sales representatives of our hardware store chain across Europe to manage customer orders efficiently

2. Operations Guide

  • Create a new order: Register customer contact details, select hardware products (hammers, drill, screws, nails), specify quantities, and calculate the total price including 21% VAT.
  • View all orders: Search and view full details of a single order using its unique ID code.
